# Gimbal Master - 智能云台主控板 BSP

## 概述

Gimbal Master 是芯天下智能云台项目的主控板，类似大疆 OM7P 智能跟随模块的设计。该项目通过四片 S300 芯片 I2C 互联，实现以下 AI 功能：

- **人形检测** (Human Detection) - 子板 Card1 (主跟踪目标)
- **人脸检测 + 识别** (Face Detection/Recognition) - 子板 Card2 (目标找回)
- **手势检测** (Palm/Peace) - 子板 Card3 (交互控制)
- **KWS 语音识别 + 云台控制** - 主板

## 软件架构

### 双核分工

主控板采用 **CM4 + DSP** 双核异构架构：

| 核心 | 频率    | 职责                                         |
| ---- | ------- | -------------------------------------------- |
| DSP  | 400 MHz | KWS 语音关键词识别推理 (MFCC + VAD + DS-CNN) |
| CM4  | 200 MHz | 音频外设驱动、UWB 数据解析、蓝牙 HID 控制    |

### KWS 语音指令

通过 DSP 语音关键词识别，支持以下语音指令：

| 语音指令     | 触发动作                      |
| ------------ | ----------------------------- |
| "拍张照片"   | 蓝牙 HID 发送音量+ (手机拍照) |
| "开始录像"   | 蓝牙 HID 长按音量+ (开始录像) |
| "停止录像"   | 蓝牙 HID 发送音量+ (停止录像) |
| "启动跟随"   | 开启视觉跟踪模式              |
| "结束跟随"   | 退出视觉跟踪模式              |
| "打开补光灯" | 控制 LED 补光灯开启           |
| "关闭补光灯" | 控制 LED 补光灯关闭           |

### UWB 辅助定位

当视觉跟踪丢失目标时，通过 UWB ULM3 PDOA 模组获取目标方位：

- **AOA 测量**: 提供目标相对于云台的角度信息
- **距离测量**: 提供目标距离 (厘米)
- **多标签支持**: 最多支持 4 个 UWB 标签

### 蓝牙 HID 手机控制

通过 XM04 蓝牙模组，以 HID 键盘模式控制手机：

- **拍照**: 发送音量+键码 (iOS/Android 相机快门)
- **录像**: 长按音量+键码触发录像
- **兼容性**: 支持 iOS 和 Android 设备

### 子板 I2C 通信

主板通过 I2C1 (PA0/PA1) 与三个 AI 子板通信，实现多维度目标感知：

| 子板  | I2C 地址 | 检测算法          | 触发动作                  |
| ----- | -------- | ----------------- | ------------------------- |
| Card1 | 0x10     | 人形检测          | 主跟踪目标，云台跟随      |
| Card2 | 0x11     | 人脸检测 + 识别   | 目标丢失后，人脸 ID 找回  |
| Card3 | 0x12     | 手势 (Palm/Peace) | Palm=启停跟踪, Peace=拍照 |

## 主要外设

### 通信接口

| 接口  | 引脚              | 功能说明                            |
| ----- | ----------------- | ----------------------------------- |
| UART2 | PA23(RX)/PA24(TX) | **RX**: UWB 接收 / **TX**: 调试打印 |
| UART1 | PA16(RX)/PA17(TX) | 蓝牙 XM04 (HID/SPP 模式)            |
| UART3 | PA26(RX)/PA27(TX) | 总线舵机控制 (半双工)               |
| I2C1  | PA0(SCL)/PA1(SDA) | 子板通信总线                        |
| I2C3  | PA4(SCL)/PA5(SDA) | 板载外设总线                        |

> **说明**: UWB ULM3 模组只需单向接收 AOA/距离数据，因此 UART2_TX 复用为调试打印输出。

### I2C1 子板设备

| 子板  | I2C 地址 | 功能说明          |
| ----- | -------- | ----------------- |
| Card1 | 0x10     | 人形检测 (主跟踪) |
| Card2 | 0x11     | 人脸检测/识别     |
| Card3 | 0x12     | 手势检测          |

| 设备     | I2C 地址 | 功能说明        |
| -------- | -------- | --------------- |
| OV5640   | 0x3C     | 摄像头          |
| ES8311   | 0x18     | 音频 Codec      |
| ES7210   | 0x41     | 4 通道音频 ADC  |
| QMI8658A | 0x6A     | 6 轴 IMU 传感器 |

### 摄像头接口 (DVP)

OV5640 摄像头由主板 I2C3 初始化，视频流通过 CPLD (XC2C128-7VQG100I) 分发到主板和三个子板：

| 输出通道 | 目标  | 用途                |
| -------- | ----- | ------------------- |
| DVP0     | 主板  | LCD 显示 + 视频录制 |
| DVP1     | Card1 | 人形检测推理        |
| DVP2     | Card2 | 人脸检测/识别推理   |
| DVP3     | Card3 | 手势检测推理        |

| 引脚      | GPIO | 功能说明 |
| --------- | ---- | -------- |
| XCLK      | -    | 时钟输出 |
| PCLK      | -    | 像素时钟 |
| HSYNC     | -    | 行同步   |
| VSYNC     | -    | 场同步   |
| DATA[7:0] | -    | 数据总线 |
| PWDN      | PA6  | 省电控制 |
| RSTN      | PA15 | 复位     |

### 显示接口 (SPI LCD)

| 信号 | 主板 GPIO | 经 TXS0108E 转换 |
| ---- | --------- | ---------------- |
| CS_N | -         | 3.3V 电平        |
| DC   | -         | 3.3V 电平        |
| SCK  | -         | 3.3V 电平        |
| SDO  | -         | 3.3V 电平        |
| RSTN | -         | 3.3V 电平        |
| BL   | PA12      | 背光控制         |

### 音频系统

- **ES8311**: 音频 Codec，用于语音播放
- **ES7210**: 4 通道 ADC，用于麦克风阵列
- **NS4150**: 功放芯片，控制引脚 PA14

### 云台控制

| 外设       | 引脚/接口        | 功能说明          |
| ---------- | ---------------- | ----------------- |
| 舵机       | UART3 (总线舵机) | 云台俯仰/偏航控制 |
| MOTO_BUSEN | PA18             | 电机总线使能      |
| QMI8658A   | I2C3             | 姿态反馈          |
| PWM 蜂鸣器 | PA20             | 声音提示          |

### RGB LED (WS2812)

| 链路     | GPIO | LED 数量 | 用途     |
| -------- | ---- | -------- | -------- |
| RGB_DIN1 | PA30 | 8        | 状态指示 |
| RGB_DIN2 | PA21 | 5        | 功能指示 |

## 使用方法

### 1. 选择板型

```bash
cmake -B build -G Ninja -DBOARD=gimbal_master .
```

或使用 VS Code 任务：
- 运行任务 "S300: Switch to Gimbal Master (云台主控板)"

### 2. 编译

```bash
ninja -C build
```

### 3. 代码示例

```c
#include "board.h"

int main(void)
{
    /* 板级初始化 (时钟、GPIO、调试串口) */
    board_init();
    
    printf("NE005 Smart Gimbal Initialized!\r\n");
    
    /* 初始化 I2C3 总线 */
#if BOARD_I2C3_ENABLE
    i2c_soft_handle_t i2c3;
    board_i2c3_init(&i2c3);
#endif

    /* 初始化摄像头 */
#if BOARD_CAMERA_ENABLE
    board_camera_ctrl_pins_init();
    board_camera_power_on_sequence();
#endif

    /* 初始化蜂鸣器 */
#if BOARD_BUZZER_ENABLE
    board_buzzer_pin_init();
    board_buzzer_beep(2700);  /* 2.7kHz 提示音 */
#endif

    while (1) {
        /* 主循环 */
    }
}
```

## 注意事项

1. **I2C 总线分工**: I2C1 用于子板通信 (Card1/2/3)，I2C3 用于板载外设 (摄像头、音频、IMU)
2. **图像分发**: OV5640 由主板 I2C3 配置，视频经 CPLD 分发到四个板子 (主板+3子板)
3. **子板设计**: 三个子板仅包含 S300 + PSRAM，无其他外设，所有外设均在主板上
4. **电平转换**: LCD 接口经过 TXS0108E 进行 1.8V ↔ 3.3V 电平转换
5. **舵机供电**: 舵机使用 5V 供电，注意电源容量
6. **子板轮询**: 主板以 50Hz 轮询子板检测结果，需控制 I2C 传输时长
