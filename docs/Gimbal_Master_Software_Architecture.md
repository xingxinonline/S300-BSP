## 1. 系统总览

### 1.1 功能概述

Gimbal Master 是智能云台项目的主控板，集成以下核心功能：

| 功能模块           | 处理位置   | 技术方案                          | 用途                    |
| ------------------ | ---------- | --------------------------------- | ----------------------- |
| **语音关键词识别** | 主板 DSP   | DS-CNN 神经网络 + MFCC + VAD      | 语音指令识别            |
| **音频采集驱动**   | 主板 CM4   | ES7210 (4ch ADC) + ES8311 (Codec) | 麦克风阵列 + 语音播放   |
| **音频源切换**     | 主板 CM4   | 模拟开关 (GPIO 控制)              | 切换板载/无线麦克风     |
| **IMU 防抖**       | 主板 CM4   | QMI8658A 6 轴 IMU + 姿态解算      | 云台机械防抖 + 跟踪融合 |
| **人形检测**       | 子板 Card1 | CNN + SORT 跟踪                   | 主跟踪目标              |
| **人脸检测+识别**  | 子板 Card2 | Face Detection + Recognition      | 目标丢失后找回          |
| **手势检测**       | 子板 Card3 | Hand Gesture (Palm/Peace)         | 交互控制                |
| **UWB 定位**       | 主板 CM4   | ULM3 PDOA 模组 (UART)             | 目标丢失后方位确认      |
| **蓝牙 HID 控制**  | 主板 CM4   | XM04 模组 (UART + AT 指令)        | 控制手机拍照/录像       |
| **云台控制**       | 主板 CM4   | 总线舵机 + PID 控制               | 平滑跟踪运动            |

### 1.2 硬件平台

| 组件        | 型号/参数                                              | 接口              |
| ----------- | ------------------------------------------------------ | ----------------- |
| 主控 SoC    | PiMCHIP S300 (CM4 200MHz + CEVA SensPro250 DSP 400MHz) | -                 |
| 摄像头      | OV5640                                                 | DVP + I2C3        |
| Audio Codec | ES8311                                                 | I2S0 + I2C3       |
| 麦克风 ADC  | ES7210 (4 通道) + 模拟开关                             | I2S0 + I2C3 + IO  |
| 麦克风 ADC  | ES7210 (4 通道)                                        | I2S0 + I2C3       |
| IMU         | QMI8658A (6 轴)                                        | I2C3 (0x6A)       |
| UWB 模组    | ULM3 PDOA                                              | UART2_RX (只接收) |
| 调试串口    | -                                                      | UART2_TX (复用)   |
| 蓝牙模组    | XM04 (BLE HID)                                         | UART1             |
| 云台舵机    | Hiwonder 总线舵机                                      | UART3 (半双工)    |
| 显示屏      | SPI LCD                                                | SPI + TXS0108E    |

> **串口复用说明**: UWB 模组只需单向接收数据（AOA 角度、距离），无需发送命令，因此 UART2_TX 引脚复用为调试打印输出，节省一个串口资源。

## 2. 双核分工设计

### 2.1 职责划分

| 核心 | 职责域              | 具体任务                                             |
| ---- | ------------------- | ---------------------------------------------------- |
| DSP  | 推理计算密集型      | MFCC 特征提取、VAD 检测、KWS 推理                    |
| CM4  | 外设驱动 + 业务逻辑 | 音频采集、子板数据融合、UWB 解析、蓝牙控制、云台控制 |

> **注**: 视觉目标检测由三个 AI 子板 (Card1/2/3) 分别完成，主板通过 I2C1 采集检测结果。

### 2.2 核间通信

采用 **Mailbox + 共享内存** 的零拷贝架构：

```
          DSP Memory                              CM4 Memory
    ┌─────────────────────┐                ┌─────────────────────┐
    │  KWS 结果区         │◄───Mailbox────│  读取结果           │
    │  DSP_KWS_BASE_ADDR  │   (偏移地址)   └─────────────────────┘
    │  0x44810000         │
    └─────────────────────┘
                                           ┌─────────────────────┐
    ┌─────────────────────┐                │  CM4 写入音频数据   │
    │  音频输入区         │◄───Mailbox────│                     │
    │  DSP_AUDIO_IN_ADDR  │   (数据就绪)   └─────────────────────┘
    │  0x44040000         │
    └─────────────────────┘
```

### 2.3 通信协议

参考 `kws_proto.h` 定义的消息格式：

| 消息方向 | 消息类型                       | Payload 含义             |
| -------- | ------------------------------ | ------------------------ |
| DSP→CM4  | `MAILBOX_MSG_TYPE_KWS`         | KWSResult 相对基址的偏移 |
| CM4→DSP  | `MAILBOX_MSG_TYPE_AUDIO_READY` | 音频数据块已就绪         |

## 3. KWS 语音识别子系统

### 3.1 采集与输入选择

系统支持两种音频输入源，通过 **GPIO10** 控制模拟开关进行切换：

- **板载麦克风 (MIC1/2)** (GPIO10 = Low): 使用 ES7210 采集板载麦克风阵列数据。
- **无线麦克风 (MIC4)** (GPIO10 = High): 切换到外部无线麦克风输入。

## 4. UWB 定位子系统

### 4.1 ULM3 PDOA 模组

ULM3 是一款支持 AOA (Angle of Arrival) 测量的 UWB 模组，用于计算目标标签的方位角。

**串口配置**：
- 接收引脚: UART2_RX (PA23)
- 波特率: 115200
- 数据格式: 8N1
- **注意**: UWB 模组只需单向接收，UART2_TX 复用为调试打印输出

### 4.2 数据协议

```
数据格式: $ssw,<TagID>,<X_cm>,<Y_cm>,<Dist_cm>,<RangNum>,<PDOA>,<AOA>,<DistOffset>,<PDOAOffset>,<DistA1>,<Key>,<AoA_A1>\r\n

示例: $ssw,01,100,200,250,5,45,30,0,0,0,0,0\r\n
```

### 4.3 数据结构

```c
typedef struct {
    uint8_t     id;             /* 标签 ID */
    float       aoa_angle;      /* AOA 角度 (度) */
    uint32_t    distance;       /* 距离 (厘米) */
    uint32_t    live_time;      /* 存活时间 (用于超时清理) */
} uwb_node;

typedef struct {
    emUART      uart;           /* 使用的串口 */
    uint32_t    node_cnt;       /* 有效节点数 */
    uwb_node    nodes[MAX_NODE_NUMBER];  /* 节点数组 (最多 4 个) */
    emTIMER     timer;          /* 超时定时器 */
} uwb_base_station;
```

### 4.4 UWB 在跟踪中的应用

当视觉跟踪丢失目标时，使用 UWB 提供的 AOA 角度进行方位确认：

```
视觉跟踪正常                      目标丢失
    │                                │
    ▼                                ▼
┌─────────────┐               ┌─────────────┐
│  视觉跟踪   │───丢失────────►│  UWB 辅助   │
│  SORT/SOT   │               │  方位确认   │
└─────────────┘               └──────┬──────┘
                                     │
                              ┌──────┴──────┐
                              │             │
                         UWB 有效        UWB 无效
                              │             │
                              ▼             ▼
                       ┌─────────────┐ ┌─────────────┐
                       │  云台转向   │ │  搜索模式   │
                       │  UWB 方位   │ │  扫描搜索   │
                       └─────────────┘ └─────────────┘
```

### 4.5 UWB 接口 API

```c

/* 获取最近的有效节点 */

/* UART 中断接收处理 */

/* 定时器超时处理 */
void uwb_timer_handle(void);
```

### 5.5 I2C 通信协议

采用寄存器式协议，主板定期轮询子板检测结果：

**寄存器定义**：

| 寄存器 | 地址 | 长度 | 说明                            |
| ------ | ---- | ---- | ------------------------------- |
| STATUS | 0x00 | 1B   | 子板状态 (0=空闲, 1=有检测结果) |
| RESULT | 0x10 | 32B  | 检测结果结构体                  |
| CONFIG | 0x80 | 8B   | 配置参数                        |

**检测结果结构体** (Card1/Card2 目标检测)：

```c
typedef struct __attribute__((packed)) {
    uint8_t  valid;         /* 结果有效标志 */
    uint8_t  target_count;  /* 检测到的目标数量 */
    uint8_t  primary_id;    /* 主要目标 ID (用于跟踪) */
    uint8_t  reserved;
    int16_t  center_x;      /* 主目标中心 X (图像坐标) */
    int16_t  center_y;      /* 主目标中心 Y */
    uint16_t width;         /* 主目标宽度 */
    uint16_t height;        /* 主目标高度 */
    uint8_t  confidence;    /* 置信度 [0-100] */
    uint8_t  face_id;       /* 人脸 ID (仅 Card2，0=未识别) */
    uint8_t  reserved2[18]; /* 预留 */
} detection_result_t;       /* 32 bytes */
```

**手势结果结构体** (Card3)：

```c
typedef struct __attribute__((packed)) {
    uint8_t  valid;         /* 结果有效标志 */
    uint8_t  gesture_type;  /* 手势类型: 0=无, 1=Palm, 2=Peace */
    uint8_t  confidence;    /* 置信度 [0-100] */
    uint8_t  hand_count;    /* 检测到的手数量 */
    int16_t  center_x;      /* 手势中心 X */
    int16_t  center_y;      /* 手势中心 Y */
    uint8_t  reserved[24];  /* 预留 */
} gesture_result_t;         /* 32 bytes */
```

### 5.8 人脸识别找回机制

当主跟踪目标 (人形) 丢失时，使用预存的人脸特征进行找回：

1. **特征注册**：跟踪开始时，记录目标的 Face ID
2. **丢失检测**：Card1 连续 N 帧未检测到人形
3. **人脸搜索**：主板请求 Card2 进行人脸识别匹配
4. **目标恢复**：匹配成功后，云台转向人脸位置，恢复跟踪

```c
/* 人脸找回流程 */
void tracking_face_recovery(void)
{
    detection_result_t face_result;
    
    /* 读取 Card2 人脸检测结果 */
    i2c_read(EM_I2C1, CARD2_ADDR, REG_RESULT, false, 
             (uint8_t*)&face_result, sizeof(face_result));
    
    if (face_result.valid && face_result.face_id == g_tracked_face_id) {
        /* 找到目标人脸，云台转向 */
        gimbal_set_target(face_result.center_x, face_result.center_y);
        tracking_set_state(TRACKING_STATE_LOCK);
    }
}
```

### 6.1 XM04 模组概述

XM04 是一款支持 HID 协议的蓝牙 BLE 模组，可以模拟键盘、鼠标等 HID 设备，用于控制手机。

**串口配置**：
- 串口: UART1 (PA16/PA17)
- 波特率: 可配置 (默认 9600)
- AT 模式控制: PA21 (高电平进入 AT 模式)

### 6.2 工作模式

| 模式 | 值   | 说明              |
| ---- | ---- | ----------------- |
| HID  | 0x00 | HID 键盘/鼠标服务 |

### 6.3 HID Report ID

| Report ID | 用途          | 数据长度 |
| --------- | ------------- | -------- |
| 0x01      | 键盘          | 8 字节   |
| 0x03      | Consumer 控制 | 4 字节   |
| 0x04      | System 控制   | 1 字节   |

### 6.4 手机拍照控制

利用 iOS/Android 的音量键拍照功能，通过 HID Consumer Control 发送音量控制：

| 功能     | Consumer Key Code | 说明             |
| -------- | ----------------- | ---------------- |
| 拍照     | 0x00E9            | Volume Up        |
| 开始录像 | 0x00E9            | Volume Up (长按) |
| 停止录像 | 0x00E9            | Volume Up        |

### 6.5 KWS 到蓝牙的映射

```c
void kws_action_handler(KWSKeyword_t keyword)
{
    switch (keyword) {
    case KWS_KEYWORD_TAKE_PHOTO:
        /* 发送音量+ 键码，触发手机拍照 */
        xm04_send_consumer_control_key(0x00E9);  /* Volume Up */
        delay_ms(100);
        xm04_release_all_keys();
        break;

    case KWS_KEYWORD_START_RECORDING:
        /* 长按音量+，开始录像 */
        xm04_send_consumer_control_key(0x00E9);
        delay_ms(1000);  /* 长按 1 秒 */
        xm04_release_all_keys();
        break;

    case KWS_KEYWORD_STOP_RECORDING:
        /* 点按音量+，停止录像 */
        xm04_send_consumer_control_key(0x00E9);
        delay_ms(100);
        xm04_release_all_keys();
        break;

    case KWS_KEYWORD_START_TRACKING:
        tracking_fsm_set_state(TRACKING_STATE_ACTIVE);
        break;

    case KWS_KEYWORD_STOP_TRACKING:
        tracking_fsm_set_state(TRACKING_STATE_IDLE);
        break;

    default:
        break;
    }
}
```

## 7. IMU 防抖子系统

### 7.1 QMI8658A 概述

QMI8658A 是一款高精度 6 轴 IMU（三轴加速度计 + 三轴陀螺仪），用于云台系统的姿态感知和电子防抖。

**主要特性**：
- 陀螺仪范围: ±16 ~ ±2048 dps
- 加速度计范围: ±2g ~ ±16g
- 输出数据率 (ODR): 最高 8kHz
- 低延迟: < 2ms
- I2C 地址: 0x6A (I2C3 总线)

### 7.2 防抖架构

```

│  │  陀螺仪     │   │   (LPF)     │   │ (Yaw/Pitch)│   │ → 云台控制 │  │
```

### 7.3 防抖策略

| 防抖模式     | 触发条件     | 补偿方式                          |
| ------------ | ------------ | --------------------------------- |
| **机械防抖** | 始终启用     | 云台舵机实时补偿 IMU 检测的角速度 |
| **电子防抖** | 视频录制时   | 附加 IMU 数据供后期稳像处理       |
| **跟踪融合** | 跟踪模式激活 | IMU 补偿视觉延迟，提高跟踪平滑度  |

### 7.4 姿态解算

采用互补滤波器融合陀螺仪和加速度计数据：

```c
/* 姿态数据结构 */
typedef struct {
    float pitch;        /* 俯仰角 (deg) */
    float roll;         /* 横滚角 (deg) */
    float yaw;          /* 航向角 (deg) - 零漂移参考 */
    float gyro_x;       /* 角速度 X (dps) */
    float gyro_y;       /* 角速度 Y (dps) */
    float gyro_z;       /* 角速度 Z (dps) */
} imu_attitude_t;

/* 防抖配置 */
typedef struct {
    float lpf_cutoff;       /* 低通滤波截止频率 (Hz) */
    float comp_alpha;       /* 互补滤波系数 (0.0-1.0) */
    bool  gyro_comp_en;     /* 陀螺仪补偿使能 */
    float gyro_gain;        /* 陀螺仪补偿增益 */
} imu_stab_config_t;
```

### 7.5 云台融合控制

将 IMU 防抖与视觉跟踪融合，实现平滑的云台控制：

```c
/* 云台控制融合 */
void gimbal_control_update(void)
{
    imu_attitude_t imu;
    target_pos_t   visual_target;
    
    /* 1. 读取 IMU 姿态 */
    imu_get_attitude(&imu);
    
    /* 2. 获取视觉目标 (来自子板 Card1) */
    if (tracking_get_target(&visual_target)) {
        /* 3. 视觉 + IMU 融合 */
        float pan_cmd  = visual_target.pan_error  - imu.gyro_z * GYRO_COMP_GAIN;
        float tilt_cmd = visual_target.tilt_error - imu.gyro_y * GYRO_COMP_GAIN;
        
        /* 4. PID 输出到舵机 */
        servo_set_position(SERVO_PAN,  pid_update(&pid_pan,  pan_cmd));
        servo_set_position(SERVO_TILT, pid_update(&pid_tilt, tilt_cmd));
    } else {
        /* 无视觉目标，仅防抖补偿 */
        float pan_comp  = -imu.gyro_z * GYRO_STAB_GAIN;
        float tilt_comp = -imu.gyro_y * GYRO_STAB_GAIN;
        
        servo_adjust_position(SERVO_PAN,  pan_comp);
        servo_adjust_position(SERVO_TILT, tilt_comp);
    }
}
```

## 8. 系统集成

### 8.1 主循环架构

```c
int main(void)
{
    /* 1. 板级初始化 */
    board_init();
    
    /* 2. 外设初始化 */
    audio_init();           /* ES7210 + ES8311 */
    debug_uart_init();      /* UART2_TX 调试打印 */

    ble_set_mode(BLE_MODE_HID);

    while (1) {
        /* KWS 轮询 */
        kws_poll_process();

        /* 云台控制更新 */
```

## 10. 外设驱动

### 10.1 WS2812 RGB LED 灯带

云台主控板配备两条 WS2812B RGB LED 灯带，用于状态指示和氛围灯效。

#### 10.1.1 硬件配置

| 参数     | 链1 (RGB_DIN1) | 链2 (RGB_DIN2) |
| -------- | -------------- | -------------- |
| GPIO     | PA15           | PA30           |
| Function | FUNCTION_2     | FUNCTION_2     |
| LED 数量 | 5 颗           | 5 颗           |
| 电平转换 | TXS0108 A7→B7  | TXS0108 A6→B6  |

**电平转换**: S300 MCU IO 为 1.8V 电平，经 TXS0108ERGYR 双向电平转换芯片转为 3.3V 信号驱动 WS2812。

#### 10.1.2 驱动实现

驱动位于 `Drivers/External/WS2812/`，采用 GPIO 位翻转 + 精确延时实现单线协议。

**关键特性**:

- 支持多链管理 (最多 2 条链，每链最多 32 颗 LED)
- 全局亮度控制 (0-255)
- HSV 到 RGB 颜色转换
- 临时禁用中断保证时序精度

**时序配置** (针对 S300 @ 200MHz):

```c
#define WS2812_T0H_CYCLES   1    /* ~200ns，发送 '0' 高电平 */
#define WS2812_T0L_CYCLES   20   /* ~1µs，发送 '0' 低电平 */
#define WS2812_T1H_CYCLES   12   /* ~0.7µs，发送 '1' 高电平 */
#define WS2812_T1L_CYCLES   8    /* ~0.4µs，发送 '1' 低电平 */
```

#### 10.1.3 使用示例

```c
#include "ws2812.h"

ws2812_handle_t handle;
ws2812_color_t buffer[5];

// 初始化
ws2812_init(&handle);
ws2812_add_chain(&handle, (void*)GPIO_BASE, BOARD_RGB_DIN1_PIN, 5, buffer);

// 设置亮度 (推荐 16-64)
ws2812_set_brightness(&handle, 32);

// 设置颜色并显示
ws2812_fill(&handle, 0, WS2812_COLOR_CYAN);
ws2812_show(&handle, 0);
```

#### 10.1.4 演示程序

演示项目 `Projects/Demo/WS2812_LED_Demo/` 提供 5 种基础效果和 14 种系统状态灯效果:

**基础效果**: 逐个点亮、彩虹流水、青色呼吸灯、八色渐变、双链交替闪烁

#### 10.1.5 系统状态灯效果 (美化版)

两条灯带用于指示系统运行状态，采用炫酷的视觉效果设计：

| 状态           | 灯效描述                             | 说明               |
| -------------- | ------------------------------------ | ------------------ |
| **启动中**     | 双彗星尾迹对冲 + 汇聚闪光            | 系统初始化         |
| **待机**       | 极光呼吸 (青绿色渐变流动)            | 等待语音命令或手势 |
| **语音唤醒**   | 绿色涟漪扩散 (从中心向外)            | 检测到有效关键词   |
| **跟踪中**     | 暖冷双色彩虹追逐                     | 正在跟踪目标       |
| **目标丢失**   | 琥珀色左右扫描                       | 搜索目标中         |
| **UWB 辅助**   | 紫色雷达扫描 (带渐变尾迹)            | 使用 UWB 定位辅助  |
| **拍照**       | 闪光灯效果 (预闪→主闪光→衰减)        | 触发蓝牙 HID 拍照  |
| **录像中**     | 红色心跳脉冲 (双跳节奏)              | 正在录像           |
| **蓝牙配对**   | 蓝色呼吸 + 淡青色星点闪烁            | 等待手机配对       |
| **蓝牙已连接** | 蓝色汇聚闪光 (两端向中心)            | 配对成功提示       |
| **错误**       | 红色频闪 (双闪节奏)                  | 系统异常           |
| **低电量**     | 橙红渐变警告 (仅链1)                 | 电量不足警告       |
| **板载麦克风** | 青色波浪 + 确认闪光                  | 切换到板载 MIC1/2  |
| **无线麦克风** | 紫色无线波 (多层波纹扩散) + 紫粉渐变 | 切换到无线 MIC4    |

**灯效 API 设计**:

```c
/* 状态灯效果枚举 */
typedef enum {
    LED_EFFECT_BOOT,            /* 启动 - 双彗星尾迹 */
    LED_EFFECT_IDLE,            /* 待机 - 极光呼吸 */
    LED_EFFECT_VOICE_WAKEUP,    /* 语音唤醒 - 绿色涟漪 */
    LED_EFFECT_TRACKING,        /* 跟踪中 - 双彩虹追逐 */
    LED_EFFECT_TARGET_LOST,     /* 目标丢失 - 琥珀扫描 */
    LED_EFFECT_UWB_ASSIST,      /* UWB 辅助 - 紫色雷达 */
    LED_EFFECT_CAPTURE,         /* 拍照 - 闪光灯效果 */
    LED_EFFECT_RECORDING,       /* 录像中 - 心跳脉冲 */
    LED_EFFECT_BLE_PAIRING,     /* 蓝牙配对 - 星点闪烁 */
    LED_EFFECT_BLE_CONNECTED,   /* 蓝牙已连接 - 汇聚闪光 */
    LED_EFFECT_ERROR,           /* 错误 - 红色频闪 */
    LED_EFFECT_LOW_BATTERY,     /* 低电量 - 橙红渐变 */
    LED_EFFECT_MIC_ONBOARD,     /* 板载麦克风 - 青色波浪 */
    LED_EFFECT_MIC_WIRELESS,    /* 无线麦克风 - 紫色无线波 */
} led_effect_t;

/* 设置当前状态灯效果 */
void led_set_effect(led_effect_t effect);

/* 临时效果 (播放完毕自动恢复之前状态) */
void led_play_once(led_effect_t effect);
```
