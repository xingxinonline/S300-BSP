# WS2812 RGB LED 灯带演示

> **状态**: ✅ 已在 Gimbal Master 硬件上验证通过 (2026-03-04)

## 简介

本演示程序展示如何使用 WS2812 驱动控制两条 RGB LED 灯带。

## 硬件连接

| 灯带 | GPIO | 说明                                |
| ---- | ---- | ----------------------------------- |
| 链1  | PA15 | 经 TXS0108 电平转换 (A7→B7)，5颗LED |
| 链2  | PA30 | 经 TXS0108 电平转换 (A6→B6)，5颗LED |

**电平转换说明**: S300 MCU IO 为 1.8V 电平，通过 TXS0108ERGYR 电平转换芯片转为 3.3V 信号驱动 WS2812。

## 演示效果

### 基础效果

1. **逐个点亮** (Pixel Chase): RGB三色依次逐个点亮
2. **彩虹流水** (Rainbow): 彩虹色流动效果
3. **呼吸灯** (Breathe): 青色呼吸效果 (亮度 0-64 渐变)
4. **颜色渐变** (Color Fade): 八种颜色依次切换
5. **交替闪烁** (Alternate Blink): 两条灯带青色交替闪烁

### 系统状态灯效果 (美化版)

| 状态           | 灯效描述                      |
| -------------- | ----------------------------- |
| **启动中**     | 双彗星尾迹对冲 + 汇聚闪光     |
| **待机**       | 极光呼吸 (青绿色渐变流动)     |
| **语音唤醒**   | 绿色涟漪扩散 (从中心向外)     |
| **跟踪中**     | 暖冷双色彩虹追逐              |
| **目标丢失**   | 琥珀色左右扫描                |
| **UWB 辅助**   | 紫色雷达扫描 (带渐变尾迹)     |
| **拍照**       | 闪光灯效果 (预闪→主闪光→衰减) |
| **录像中**     | 红色心跳脉冲 (双跳节奏)       |
| **蓝牙配对**   | 蓝色呼吸 + 淡青色星点闪烁     |
| **蓝牙已连接** | 蓝色汇聚闪光 (两端向中心)     |
| **错误**       | 红色频闪 (双闪节奏)           |
| **低电量**     | 橙红渐变警告 (仅链1)          |

### 麦克风切换状态灯

| 状态           | 灯效描述                             |
| -------------- | ------------------------------------ |
| **板载麦克风** | 青色波浪 (中心亮，两边暗) + 确认闪光 |
| **无线麦克风** | 紫色无线波 (多层波纹扩散) + 紫粉渐变 |

演示循环播放：基础效果 → 系统状态灯效果 → 麦克风状态灯 → 重复

## 亮度设置

- 默认亮度: 32/255 (约 12.5%)，避免刺眼
- 呼吸灯最大亮度: 64/255 (约 25%)
- 可通过 `ws2812_set_brightness()` 调整

## API 使用示例

```c
#include "ws2812.h"

// 创建句柄和缓冲区
ws2812_handle_t handle;
ws2812_color_t buffer[5];

// 初始化
ws2812_init(&handle);
ws2812_add_chain(&handle, (void*)GPIO_BASE, 15, 5, buffer);

// 设置亮度 (推荐 16-64，避免刺眼)
ws2812_set_brightness(&handle, 32);

// 设置颜色
ws2812_set_pixel(&handle, 0, 0, WS2812_COLOR_RED);   // 第0颗LED红色
ws2812_fill(&handle, 0, WS2812_COLOR_BLUE);          // 全部蓝色

// 刷新显示
ws2812_show(&handle, 0);

// HSV 颜色 (彩虹效果常用)
ws2812_color_t rainbow = ws2812_hsv(120, 255, 255);  // 绿色

// 自定义颜色
ws2812_color_t custom = ws2812_rgb(255, 128, 0);     // 橙色
```

## 注意事项

1. WS2812 对时序要求严格，驱动会临时禁用中断以保证精度
2. 灯带供电建议使用独立 5V 电源，避免 MCU 供电不足
3. 长灯带需要在适当位置补充供电
4. GPIO 必须配置为 FUNCTION_2 (GPIO 功能)
