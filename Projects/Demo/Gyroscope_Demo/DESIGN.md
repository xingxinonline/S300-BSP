# Gyroscope Demo 设计文档

## 1. 概述

本 Demo 演示使用 QMI8658A 六轴 IMU 传感器配合总线舵机实现云台自稳功能。系统读取加速度计数据，计算设备相对于重力的倾斜角度，通过 PID 控制算法驱动舵机补偿，使设备保持与地面垂直。

## 2. 硬件配置

### 2.1 硬件连接 (gimbal_master 板)

| 外设     | GPIO       | 说明         |
| -------- | ---------- | ------------ |
| I2C3 SCL | GPIOA4     | IMU 时钟线   |
| I2C3 SDA | GPIOA5     | IMU 数据线   |
| UART2 TX | GPIOA23    | 调试串口     |
| UART2 RX | GPIOA24    | 调试串口     |
| UART3 TX | GPIOA27    | 总线舵机     |
| UART3 RX | GPIOA26    | 总线舵机     |
| GPIO22   | MOTO_BUSEN | 舵机方向控制 |

### 2.2 IMU 传感器

- **型号**: QMI8658A
- **I2C 地址**: 0x6A
- **功能**: 6 轴（3 轴加速度计 + 3 轴陀螺仪）
- **本 Demo 仅使用加速度计**进行倾斜角计算

### 2.3 舵机配置

| 舵机 ID | 功能              | 脉冲范围  | 角度范围    |
| ------- | ----------------- | --------- | ----------- |
| 3       | Roll (侧倾) 补偿  | 125 - 875 | -90° ~ +90° |
| 2       | Pitch (俯仰) 补偿 | 125 - 875 | -90° ~ +90° |

**脉冲转换系数**: 4.17 脉冲/度 (1000脉冲 / 240°)

## 3. IMU 安装方向与目标角度

### 3.1 坐标系定义

```
当设备处于期望"垂直"位置时：
        
      Z (水平)
      ↑
      |
      +──→ X (水平)
     /
    ↓
    Y (朝下 = 重力方向)

加速度读数: Acc = (0, -g, 0) ≈ (0, -9.8, 0)
```

### 3.2 角度计算公式

```c
Roll  = atan2(Acc_Y, Acc_Z) * (180/π)   // 侧倾角
Pitch = atan2(-Acc_X, √(Acc_Y² + Acc_Z²)) * (180/π)  // 俯仰角
```

### 3.3 目标角度

根据 IMU 安装方向分析：

| 参数         | 目标值   | 推导                  |
| ------------ | -------- | --------------------- |
| TARGET_ROLL  | **-90°** | `atan2(-g, 0) = -90°` |
| TARGET_PITCH | **0°**   | `atan2(0, g) = 0°`    |

## 4. 控制系统设计

### 4.1 系统框图

```
                    ┌─────────────┐
   目标角度 ───────►│             │
   (Roll=-90°)      │   误差计算   │───► roll_error
                    │             │
   当前角度 ───────►│             │
   (filtered_roll)  └─────────────┘
                           │
                           ▼
                    ┌─────────────┐
                    │             │
                    │  PID 控制器  │───► roll_comp (补偿角度)
                    │             │
                    └─────────────┘
                           │
                           ▼
                    ┌─────────────┐
                    │             │
                    │  速率限制    │───► servo_roll_angle
                    │             │
                    └─────────────┘
                           │
                           ▼
                    ┌─────────────┐
                    │             │
                    │ 脉冲转换    │───► roll_pulse
                    │ MID + angle │
                    │ * 4.17      │
                    └─────────────┘
                           │
                           ▼
                      [总线舵机]
```

### 4.2 PID 参数

| 参数         | Roll | Pitch | 说明                          |
| ------------ | ---- | ----- | ----------------------------- |
| Kp           | 1.0  | 1.0   | 比例增益，1.0 = 完全补偿      |
| Ki           | 0.5  | 0.5   | 积分增益，消除稳态误差        |
| Kd           | 0.0  | 0.0   | 微分增益，设为 0 避免噪声放大 |
| INTEGRAL_MAX | 100° | 100°  | 积分限幅                      |

### 4.3 控制算法

```c
// 1. 误差计算
roll_error = filtered_roll - TARGET_ROLL;

// 2. PID 计算
if (|roll_error| > DEADZONE) {
    P = Kp * roll_error;
    I += Ki * roll_error * dt;  // 带积分限幅
    D = Kd * (roll_error - last_error) / dt;
    
    // 3. 反向补偿（舵机与传感器同向安装）
    roll_comp = -(P + I + D);
} else {
    I = 0;  // 死区内清除积分
}

// 4. 速率限制
roll_comp = clamp(roll_comp, last ± RATE_LIMIT);

// 5. 脉冲转换
roll_pulse = MID_PULSE + roll_comp * PULSE_PER_DEGREE;
```

### 4.4 补偿方向说明

**为什么用负号 `roll_comp = -(P + I + D)`？**

- 当设备向右倾斜时，`roll_error > 0`
- 舵机需要向左转动来补偿
- 舵机与 IMU 同向安装，所以需要取反

## 5. 信号处理

### 5.1 低通滤波 (LPF)

```c
filtered = α * current + (1-α) * filtered_prev
```

| 参数      | 值  | 说明                   |
| --------- | --- | ---------------------- |
| LPF_ALPHA | 0.1 | 越小越平滑，但响应越慢 |

### 5.2 死区

| 参数         | 值   | 说明               |
| ------------ | ---- | ------------------ |
| DEADZONE_DEG | 1.0° | 误差小于此值不响应 |

### 5.3 速率限制

| 参数             | 值       | 说明         |
| ---------------- | -------- | ------------ |
| SERVO_RATE_LIMIT | 10°/周期 | 防止舵机突变 |

## 7. 已知问题与修复记录

### 7.1 I2C 多字节读取 Bug (已修复)

**问题**: 软件 I2C 多字节读取时，SDA 没有释放，导致数据始终为 0xFF。

**修复**: 在 `i2c_soft_read_byte()` 中，读取前先设置 SDA 为输入（释放总线）。

```c
void i2c_soft_read_byte(i2c_soft_t *i2c, uint8_t *byte, bool ack)
{
    i2c_sda_in(i2c);  // 释放 SDA，让从设备驱动
    ...
}
```

### 7.2 舵机轴向映射 (已确认)

通过 TEST_MODE 1 确认：

| 舵机 ID | 控制轴       |
| ------- | ------------ |
| 3       | Roll (侧倾)  |
| 2       | Pitch (俯仰) |

### 7.3 角度-脉冲转换 (已修复)

**问题**: 直接用角度值作为脉冲偏移，导致补偿不足。

**修复**: 添加 `PULSE_PER_DEGREE = 4.17` 系数。

```c
roll_pulse = MID_PULSE + servo_roll_angle * PULSE_PER_DEGREE;
```

### 7.4 目标角度 (已修复)

**问题**: 原本假设 Roll=0, Pitch=0 为垂直，但 IMU 安装方式决定了垂直时 Roll=-90°。

**修复**: 根据加速度计数据分析 IMU 安装方向，确定 `TARGET_ROLL = -90°`。

## 8. 调参建议

1. **响应太慢**: 增大 `ROLL_KP` 或减小 `LPF_ALPHA`
2. **有稳态误差**: 增大 `ROLL_KI` 或 `INTEGRAL_MAX`
3. **振荡/抖动**: 减小 `ROLL_KP`，增大 `LPF_ALPHA`，或增大死区
4. **舵机突变**: 减小 `SERVO_RATE_LIMIT`
